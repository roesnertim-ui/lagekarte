# Lagekarte

Offline nutzbares Skizzenwerkzeug für Einsatzlagen (Lageplan, Grundriss, Gebäudeschnitt, TH/VU) mit taktischen Zeichen.
Läuft im Browser und als App auf dem Home-Bildschirm (iPad/iPhone/Android). Alle Einsatzdaten bleiben lokal auf dem Gerät.

Taktische Zeichen nach dem Zeichensatz „Taktische-Zeichen“ von Jonas Köritz (CC BY 4.0), angelehnt an die DV 102.
Fahrzeuge, Grundriss- und Schnittelemente sind eigene Darstellungen. Kein amtlicher Zeichensatz.

Bei Änderungen an den Dateien in `sw.js` die Konstante `VERSION` erhöhen, damit installierte Geräte aktualisieren.
